# PicPic

Flutter 姿势引导相机。选择一个人偶，点击顶部提示查看三个动作步骤，拖动、双指缩放或旋转人偶。工具栏支持网格、镜像和透明度。使用实时取景拍照后，可把没有人偶的原始照片保存到系统相册。支持三秒倒计时。

首页、姿势库、创作和个人中心共用四个导航入口。姿势库内置 24 张人偶图与 76 张骨架插画，包含 20 个双人参考。收藏、拍摄计划、使用次数和成片索引保存在本机 SQLite。在创作页选择单人参考照片，端侧 MediaPipe 会提取人体轮廓和关节。保存后可用自己的姿势取景。支持匹配的单人模板在相机内提供「开启动作匹配」。20 个双人模板可按取景器左位和右位分别提示。iPhone 可离线识别场景并推荐姿势。照片 Studio 和 Android 云端场景识别的服务配置见 docs/阶段5-部署与验证.md。

在真机上运行

    flutter pub get
    flutter run

无摄像头或相机权限未开启时，可选择示例取景，使用项目自带的街景和 100 个离线姿势试用。示例快门仅预览。

    flutter analyze
    flutter test
