# 阶段 4 · 单人姿势识别

## 在手机上体验

1. 在「创作 → 自定义姿势」选一张光线清晰的单人照片，尽量让四肢入镜。查看提取的人体轮廓，命名并保存。「我的 → 我的自定义姿势」可以重新打开。
2. 在详情里点「开始拍摄」。有参考关节的单人姿势会显示「开启动作匹配」。打开后，将身体放入画面并调整动作。再次点该控件可关闭。
3. 按快门时停止分析，预览和分享使用原片。无识别结果或可见关节不足时，界面提供入镜提示。

## 实现和覆盖范围

- MediaPipe Pose Landmarker Lite 与原生推理库随应用打包。本地推理返回 33 个关节。PicPic 使用鼻部、两肩、肘、腕、髋、膝和踝这 13 个位置，按可见度和存在置信度筛选。
- 导入照片会同时运行前景分割。将分割结果转换为单色矢量轮廓，按同一边界裁剪关节与轮廓，保持宽高比。SQLite 升级到版本 2，保存名称、轮廓、比例和有效关节。用户选中的原始照片不写入姿势数据库。
- 56 个单人插画模板使用作者定义的关节；24 张既有人偶图中，23 张提取到至少 7 个可用关节。「交叉站立」与 20 个双人模板当前提供手动对齐。
- 取景时最多约每 220 毫秒接收一帧，上一帧仍在处理时直接跳过。小尺寸 RGB 输入交由原生模型的视频模式推理。匹配分数依据可见骨段的二维方向差，允许拍摄者与目标身高、位置和距离不同。没有足够骨段时不显示分数。该分数不能判断纵深或精确的三维转身角度。
- iOS 部署目标 15.0。已检查随包原生推理框架的 iOS 最低版本为 15.0。Android 最低版本设为 API 28，以满足 MediaPipe 插件依赖。
- 模型来源、散列及版本见 assets/mediapipe/manifest.json。重新下载可运行 `dart run mediapipe_core:bundle_models`。

## 验证与实机边界

运行 `flutter analyze`、`flutter test`。真实模型验证在工程目录运行以下命令：

```bash
curl -fL https://storage.googleapis.com/mediapipe-assets/pose.jpg -o /tmp/picpic-person.jpg
PICPIC_POSE_SAMPLE=/tmp/picpic-person.jpg flutter test tool/model_check.dart
```

真实模型用例在 macOS 上执行静态照片识别、轮廓提取和连续两帧视频模式检测。视频输入来自同一真人样张经 BGRA 相机帧转换后的像素。数据库回归包含旧版升级、收藏保留和自定义骨架重载。iOS 开发包通过签名导出，并已通过 USB 成功安装和启动在 iPhone 6s Plus（iOS 15.8.8）上。手机端待验证前后镜头镜像、旋转、实际帧率、升温以及老款 iPhone 的相机与模型同时运行。Android 仍需 SDK、构建及真机测试。
