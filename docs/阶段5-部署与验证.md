# PicPic 阶段 5

## 手机上可以使用的功能

- 在姿势库选择「双人」或「情侣」，进入相机，点「开启动作匹配」。左位与右位按当前取景位置分配；交换位置后按新位置指导。只看见一个人、肩腰遮挡或两人中心太近时会提示调整位置。双人取景优先使用光线充足、两人全身入镜的画面。
- iPhone 在「创作 → 场景推荐」从相册选图或拍摄现场，点「在本机识别场景」。Apple Vision 检测图像标签，应用映射到十类拍摄环境，并推荐离线库中的姿势。识别不到时可手动浏览。本机识别不上传照片。
- 「照片 Studio」提供十种风格、自定义描述、生成状态、失败重试、原图对比、保存和系统分享。「我的 → AI 生成历史」读取同一云端身份下最近 100 个任务。开发包未配置云端时会显示服务状态。Android 场景识别使用同一服务的视觉模型。

## 服务配置

云端调用需要个人可控的 Supabase 开发项目和支持 Gemini generateContent 图片编辑、视觉理解的账号。模型名依据该项目当前可用模型填写。服务端与客户端各自使用如下配置。

| 设置位置 | 变量 | 用途 |
|---|---|---|
| 服务端和 Flutter 构建参数 | SUPABASE_URL、SUPABASE_PUBLISHABLE_KEY | 仅使用项目公开 key，启用 Authentication 的 Anonymous Sign-Ins |
| 服务端环境变量 | GEMINI_API_KEY、GEMINI_EDIT_MODEL、GEMINI_SCENE_MODEL | Google 凭据和任务使用的模型，编辑模型必须支持输入及输出图片 |
| 服务端环境变量 | PICPIC_DB | 可写持久卷中的 SQLite 文件，默认 data/picpic.sqlite |
| 服务端环境变量 | GLOBAL_DAILY_LIMIT、USER_DAILY_LIMIT、RETENTION_DAYS | 默认全服务每 24 小时 100 次、每用户 10 次，保留 30 天 |
| Flutter 构建参数 | PICPIC_AI_URL | 可由手机访问的 HTTPS 服务根地址 |

在服务器的项目根目录配置上述环境变量后执行：

```bash
python3 -m venv server/.venv
server/.venv/bin/pip install -r server/requirements.txt
server/.venv/bin/uvicorn app:app --app-dir server --host 127.0.0.1 --port 8080 --workers 1 --no-access-log
```

通过 HTTPS 反向代理访问此端口，限制请求体 8 MiB。当前 SQLite 队列使用单个服务进程。由进程管理器负责重启并挂载持久卷。在 Flutter 开发机执行：

```bash
flutter run --dart-define=PICPIC_AI_URL="$PICPIC_AI_URL" \
  --dart-define=SUPABASE_URL="$SUPABASE_URL" \
  --dart-define=SUPABASE_PUBLISHABLE_KEY="$SUPABASE_PUBLISHABLE_KEY"
```

通过匿名 Supabase 会话访问任务。重新安装客户端可能丢失匿名身份。服务端向 Supabase 核验用户 token，按 owner 限制历史、图片及重试。照片经尺寸检查、EXIF 方向校正并转存 JPEG。原图副本和生成结果作为 SQLite BLOB 存储。已结束任务按保留期限清理。数据库建表语句在 server/app.py 的 SCHEMA。阶段 6 的订阅和跨设备账号绑定另行实施。

## 本地验证

```bash
flutter analyze
flutter test
cd server && .venv/bin/python -m unittest -v
```

服务测试使用隔离的临时数据库及测试替身，覆盖任务失败、显式重试、去重、图片读取、用户隔离、服务未配置和非法输入。真实 Gemini 输出的身份保真程度、远程服务延迟及配额行为须使用测试项目验收。无真实凭据时不产生付费请求。

模型来源：[Apple Vision](https://developer.apple.com/documentation/vision/vnclassifyimagerequest)、[MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)、[Gemini 图像编辑](https://ai.google.dev/gemini-api/docs/image-generation)。

## 本次实测记录

- Flutter 静态分析通过，11 项 Flutter 回归测试通过。3 项服务端测试通过，包括使用本地 HTTP 替身验证 Gemini 图片输入和输出协议。
- macOS 上的 MediaPipe 原生模型在双人街景样张中识别出两组人体关节。测试使用 Ultralytics 公共 bus.jpg，裁剪范围为左 20、上 360、右 410、下 950。全画面模型漏掉一人后，分区补检恢复了第二人。近距离半身照出现过漏检；两人全身入镜时更适合此流程。
- Apple Vision 在工程街景照片上返回 arch 等真实标签，应用将 arch 映射为建筑。该项在 Mac 上验证。手机实景十类环境的准确率和两人走动时的持续帧率尚未测量。
- 41.3 MB 开发版 IPA 已覆盖安装到 iPhone 6s Plus（iOS 15.8.8），已通过设备进程服务启动并查询到应用进程。本轮未部署云服务或发送付费修图请求，Android 未构建安装。
