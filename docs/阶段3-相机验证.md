# PicPic 相机验证

当前 iOS 开发包使用 com.poseguide.picpic，部署目标 iOS 15.0。

| 操作 | 本轮证据 | 待验收 |
| --- | --- | --- |
| 选择姿势并进入取景 | 组件测试覆盖首页搜索、详情和取景器 | 两端真机确认镜像与预览裁切 |
| 后置闪光灯 | 通过相机平台接口测试开启和关闭指令 | 在有闪光灯的设备拍摄，对比实际曝光 |
| 拍照、保存、重拍 | 组件测试覆盖快门和重拍，SQLite 测试验证持久副本及计划完成状态 | 首次授权、相册拒绝、后台恢复、连续保存 |
| 分享原片 | 成片预览传递拍摄文件路径给系统分享接口 | 在 iPhone 和 Android 上选择接收应用及取消分享 |
| iOS 开发包 | Flutter 成功归档、签名并导出 IPA | 登记设备安装及实拍 |
| Android | 代码使用 camera 和 share_plus 的 Android 实现 | 当前环境缺少 Android SDK 和连接的设备，构建与实拍待验收 |

测试使用相机平台替身及本地图片，覆盖应用行为；曝光、系统授权弹窗和接收应用的行为由真机验收。此构建保留工程默认应用图标和启动图。
